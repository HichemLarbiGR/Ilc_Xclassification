## Overview

This folder contains the scripts and data used to:

1.  **Download** WSIs from the GDC and UNI2-h features from Hugging Face
2.  **Inspect** the extracted HDF5 feature files
3.  **Generate** downscaled (1/16) PNG thumbnails of the slides

## Installation

### 1. Python environment

```bash
python3.13 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python --version                   # should print: Python 3.13.2
pip install --upgrade pip
pip install -r requirements.txt
```

### 2. System dependencies

[**OpenSlide**](https://openslide.org/) (required by `openslide-python`) must be installed at the system level — `pip` only installs the Python bindings.

```bash
# Ubuntu / Debian
sudo apt-get install openslide-tools libopenslide0

# macOS
brew install openslide

# Conda (cross-platform)
conda install -c conda-forge openslide
```

### 3. `gdc-client`

`gdc-client` is **not** a pip package. Download the binary for your platform from the [GDC Data Transfer Tool page](https://gdc.cancer.gov/access-data/gdc-data-transfer-tool) and place it in `prepros/utils/`:

```bash
chmod +x prepros/utils/gdc-client
```

## Usage

### 📥 Download WSIs from the GDC

The script downloads a fixed list of open-access WSIs (identified by their GDC file UUIDs) into the **current working directory**, one sub-folder per file.

```bash
cd /path/to/where/data/should/be/stored
bash /path/to/ilc_Xclass_20261026/prepros/utils/get_wsi_tcga_pred.sh
```

> [!NOTE]
> Controlled-access files would require an authentication token (`-t <token.txt>`); the files listed here are open-access.

### 📥 Download UNI2-h features (TCGA-BRCA)

The UNI2-h patch features are hosted on the Hugging Face Hub in the gated dataset [`MahmoodLab/UNI2-h-features`](https://huggingface.co/datasets/MahmoodLab/UNI2-h-features).

```bash
python download_emb_TCGA_BRCA.py
```

**Prerequisites**

- A Hugging Face account with access to the dataset
- A personal access token (set it in the script or, preferably, export `HF_TOKEN` in your environment)

The archives `TCGA-BRCA_IDC.tar.gz` and `TCGA-BRCA_OTHERS.tar.gz` are downloaded into `UNI2-h_features/` and are **not** extracted automatically. After download, move them to `UNI2/` and extract them so that the `.h5` files end up next to the others.

###  Inspect an HDF5 feature file

```bash
python utils/explore_h5.py
```

Edit the `fpath` variable in the script to point to the `.h5` file you want to inspect (e.g. one of the files in `HOPT0/` or `UNI2/`). The script prints:

- file name and size
- root attributes
- recursive structure (groups / datasets)
- per-dataset details: shape, dtype, size, compression, attributes, min / max / mean / std, NaN count
- a short head preview of each dataset

###  Generate 1/16 PNG thumbnails of WSIs

```bash
python utils/wsi_to_png.py data/wsi data/png_wsi
```

- Reads each WSI at the pyramid level closest to a 1/16 downsample factor and resizes to the exact target size when needed.
- Supported extensions: `.svs`, `.ndpi`, `.mrxs`, `.tif`, `.tiff`, `.vms`, `.scn`.
- Output files are named `<slide_name>_1_16.png`.

## Notes

- **Python version** — this project targets **Python 3.13.2**. Dependency lower bounds in `requirements.txt` are chosen so that `cp313` wheels exist on PyPI (no source builds needed). Older Python interpreters are not supported by these versions.
- **`gdc-client`** — intentionally **not** committed (large, platform-specific); install it as described [above](#3-gdc-client).
- **Hugging Face token** — the token in `download_emb_TCGA_BRCA.py` should be replaced by your own. For production use, prefer reading it from an environment variable:

  ```python
  import os
  from huggingface_hub import login

  login(token=os.environ["HF_TOKEN"])
  ```

- **Large data** — exclude it from version control. Suggested `.gitignore`:

  ```gitignore
  data/wsi/
  data/png_wsi/
  HOPT0/
  UNI2/
  UNI2-h_features/
  utils/gdc-client
  *.tar.gz
  ```

- **`list_wsi_UNI2_emb.txt`** is the authoritative mapping between slide names and their UNI2-h embedding files; keep it under version control.
